## 网络场景

- 飞行模式启动：显示已有缓存，不丢失待同步操作。
- 2G/高延迟：界面保持可操作，不重复提交。
- 请求中断：操作进入队列，自动重试达到 5 次上限后保留可见失败项，不静默丢弃；在设置页检查失败数量并手动“重试同步”。
- 重启与并发：断网排队后结束进程、重启、联网重放；让旧请求迟到，核验不覆盖新状态。自动化已有覆盖，仍须逐设备补真机证据，不能据此将矩阵标为完成。
- 多设备冲突：以服务端同步策略为准，最终状态一致。
