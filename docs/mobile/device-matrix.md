## 网络场景

- 飞行模式启动：显示已有缓存，不丢失待同步操作。
- 2G/高延迟：界面保持可操作，不重复提交。
- 请求中断：操作进入队列，联网后最多重试 5 次。
- 多设备冲突：以服务端同步策略为准，最终状态一致。

## 发布阈值

- 无 P0/P1 缺陷。
- 冷启动 P75 小于 2.5 秒。
- 同步成功率不低于 99%。
- 无崩溃会话比例不低于 99.5%。
- 推送有效设备送达率不低于 95%。
- 48 小时 preview soak test 后才允许 production 构建。
