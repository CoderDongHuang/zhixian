# 知线 App 商店资料

## 基本信息

- 名称：知线
- 副标题：AI 行业研究与学习
- 分类：新闻 / 教育
- 简短描述：聚合 AI 行业事件、深度分析和个性化学习任务，支持离线阅读、收藏同步、推送和语音播报。
- 支持邮箱：通过 App 内“内测反馈”联系
- 隐私政策：https://zhixian.asia/privacy

## 完整描述

知线帮助从业者持续跟踪 AI 公司、产品、技术和开源项目。用户可以阅读经过整理的重要事件和分析，保存离线内容，在 Web、微信小程序和正式 App 之间同步收藏与学习进度，并根据个人目标完成每日学习任务。

## 权限说明

- 通知：发送用户主动启用的行业简报和学习任务提醒。
- Face ID / 生物识别：保护本地会话，不读取生物识别数据。
- 网络：同步账号、内容、收藏、学习任务、推送令牌和 OTA 更新。
