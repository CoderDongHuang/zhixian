# V0.3.1 release acceptance

> Historical acceptance record. Current version scope and status are defined only in `docs/roadmap.md`; current production automation is paused and database upgrades use Prisma migrations.

Release date: 2026-07-29

V0.3.1 closes the performance, push reliability, AI learning, WeChat synchronization, entity knowledge graph, and automated quality gaps identified after V0.3.

## Release gates

- Unit suites for push, learning AI, WeChat synchronization, and entity merging pass.
- Playwright covers authentication, session expiry, learning fallback, task progress, recommendations, exports, WeChat token rotation, account binding, synchronization, entity search/merge, IDOR, idempotency, and hostile input.
- Pull requests run against an isolated PostgreSQL/pgvector database in GitHub Actions.
- Production smoke and performance monitors run on a schedule and alert by email.
- Temporary migration routes and secrets are removed after use.

## External security gate

The previously disclosed WeChat AppSecret must be rotated in the WeChat console and updated in Vercel Production and Preview before the final `v0.3.1` Git tag. Until that is complete, builds are release candidates and V0.4 feature work should not begin.
