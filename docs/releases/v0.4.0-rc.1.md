# V0.4.0 RC.1

Release candidate date: 2026-08-02.

This candidate contains the React Native application foundation, Expo Router experience, secure authentication, feed and full reading, offline queue and background sync, bookmark and learning synchronization, Expo push registration and receipts, speech, biometric lock, anonymous telemetry, feedback, OTA channels, Sentry integration, store assets and automated release workflows.

Automated acceptance:

- Mobile TypeScript, Jest and Expo Doctor.
- Android Hermes production export.
- Web production build and server unit tests.
- Playwright desktop/mobile API and security flows.
- Dependency audit with no critical/high findings.

External release gates still require the account owner:

- Bind the EAS project and configure GitHub secrets.
- Generate signed Android/iOS preview artifacts.
- Complete the device matrix and 48-hour soak test.
- Capture real-device store screenshots.
- Approve Apple/Google agreements and credentials.

The source tag identifies a release candidate, not a completed public store release.
