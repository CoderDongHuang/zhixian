# 知线版本路线图

更新日期：2026-08-25

本文是版本范围和状态的唯一来源。发布说明记录某个候选版本的内容，不再单独定义后续路线。

| 状态 | 版本/阶段 | 范围 | 发布条件 |
| --- | --- | --- | --- |
| 已发布 | V0.3.1 Web/PWA | 信息流、学习中心、报告导出、微信小程序、实体关系、Web Push | 已完成历史验收；生产数据库后续统一使用 Prisma migration |
| 发布候选 | V0.4.0 RC | React Native App、移动同步、Expo Push、离线阅读、语音和生物识别 | Expo SDK 57 升级、依赖门禁、EAS 绑定、签名包、真机矩阵和 48 小时稳定性测试 |
| 开发中 | V0.4 稳定性加固 | P0/P1/P2 安全、迁移、数据治理、接口和工程门禁 | 全链路测试、生产迁移备份点和账户 Actions 额度恢复 |
| 规划 | V0.5 数据质量 | 来源新鲜度、历史快照、语义聚类、审核指标 | 先恢复稳定采集与质量度量 |
| 开发完成（待发布） | V0.6 可信研究工作台 | 实体订阅、证据对照、专题集合、时间线对比、纠错闭环和研究分享 | 生产迁移、真实数据验收、用户验证与数据授权方案 |
| 设想 | V0.7 可解释趋势 | GitHub/论文/产品指标、历史对比和基础回测 | 足够长的可靠历史数据 |
| 设想 | V1.0 产品化 | 多端正式发布、运营指标、订阅分层和团队能力 | 合规、SLA、付费验证和商店发布完成 |

版本号只表达同一产品的发布序列：V0.3.1 是已发布 Web/PWA 基线；V0.4.0 是包含原生 App 的候选版本，不代表已经进入应用商店。趋势监测从 V0.5 起规划，不再复用 V0.4 的含义。
