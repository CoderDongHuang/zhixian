V0.4.0 是根包候选版本，不代表进入应用商店；V0.6-V0.8 是能力范围标签，不证明分别完成生产发布。当前不修改 package 版本号，也不把已有实现重新列为待开发。

执行顺序：安全与正确性 → 个人 Web/PWA 灰度 → 数据与可信度评测 → 用户价值验证 → 原生正式发行。未完成任务见 [后续扩展路线](../AI行业研究平台-后续扩展路线.md)，问题及验收见 [10 月复核](项目复核与个人版建设建议-2026-10-09.md)。
