# 知线版本路线图

更新日期：2026-10-09

本文是版本范围和状态的唯一来源。代码实现、隔离测试、生产验收与发布分别记录，不能相互替代。本轮基线为本地 `main` 的 `a1c7dbf`，未 fetch 或执行生产发布。

| 状态 | 版本/阶段 | 范围 | 发布条件 |
| --- | --- | --- | --- |
| 历史发布基线，本轮未核验线上版本 | V0.3.1 Web/PWA | 信息流、学习中心、报告导出、微信小程序、实体关系、Web Push | 不把历史验收当作本轮线上验收 |
| 发布候选，当前阻塞 | V0.4.0 RC | React Native App、移动同步、Expo Push、离线阅读、语音和生物识别 | 依赖安全兼容升级、同步补漏、EAS/签名、真机与 48 小时稳定性验收 |
| 基础整改已有实现，复核仍有待办 | V0.4 稳定性加固 | 历史 P0/P1/P2 安全、迁移、数据治理和工程门禁 | 本轮新问题修复、安全门禁、生产迁移/配置与 CI 验证 |
| 部分已有实现，继续度量 | V0.5 数据质量 | URL 更新、历史快照、标题聚类、基础审核策略 | 变更后重分析/向量失效、新鲜度/成本与真实样本评测；语义聚类按评测决定 |
| 开发完成，生产验收未证实 | V0.6 可信研究工作台 | 实体订阅、证据对照、专题集合、时间线对比、纠错闭环和研究分享 | 证据版本/分享并发补漏、生产迁移、真实数据与用户验证 |
| 开发完成，数据验收未完成 | V0.7 趋势监测 V0.1 | 四类指标、解释卡片、历史对比和基础回测 | 授权生产源、可靠历史序列、口径/误差/缺口验收 |
| 摘录/时间窗/执行隔离已实测，生产及质量验收未完成 | V0.8 可信研究代理 V0.1 | 专题问答、冻结原文定位、对象比较、30 天变化、确认式报告和任务审计；暂不接受自由推断 | 生产迁移、100 条人工评测、真实模型及隐私评审 |
| 开发完成，正确性补漏与用户验收未完成 | 学习升级（审计 6.4） | 事件/实体关联、知识检查、实践/代码练习、间隔复习、质量自适应 | 提交幂等、每日任务并发/时区、真实用户质量与回访评测；不另造版本号 |
| 规划 | 个人 Web/PWA 灰度 | 优先可信研究主流程 | 先修本轮 P0/P1，再配置/迁移/CI/回滚，逐步恢复运营并验证留存 |
| 暂缓 | 6.5 团队企业 / 6.6 多行业 | 团队权限、私有知识库、行业配置等 | 个人版留存和需求验证后先写独立方案，当前不进入实施 |
| 长期设想 | V1.0 产品化 | 个人版稳定运营、多端正式发布、可验证商业化 | 留存、成本、质量、合规与付费证据，不以功能数量定义完成 |

V0.4.0 是根包候选版本，不代表进入应用商店；V0.6-V0.8 是能力范围标签，不证明分别完成生产发布。当前不修改 package 版本号，也不把已有实现重新列为待开发。

执行顺序：安全与正确性 → 个人 Web/PWA 灰度 → 数据与可信度评测 → 用户价值验证 → 原生正式发行。未完成任务见 [后续扩展路线](../AI行业研究平台-后续扩展路线.md)，问题及验收见 [10 月复核](项目复核与个人版建设建议-2026-10-09.md)。
