# Edge 推送配置与错误提示补修

2026-10-11 状态：本机生产构建通过，使用安装的 Edge 隔离浏览器配置完成桌面/移动视口全链路 72/72（2.9 分钟）；新增注册错误专项 2/2（10.6 秒），Lint/应用及测试类型和 Playwright 配置检查通过。GitHub 完整 CI 待本批推送后验收。不是用户已登录 profile 中的手工验收，也不是手机真机测试。

真实本机 Edge 全链路发现测试服务器把 VAPID 公钥固定为 `dGVzdA`（四字节占位），浏览器直接拒绝 `applicationServerKey`。这是测试配置错误，不能扩大断言允许“无效密钥”来假装验收成功。

Playwright 启动隔离服务器时改为生成临时有效 P-256 公钥，测试不使用生产密钥，不将私钥写入文件。推送注册成功、当前控制器的明确超时、浏览器服务拒绝注册均分别识别；配置错误仍失败。用户界面对无效密钥与浏览器 AbortError 给出中文原因，不展示难以理解的原生英文错误。

Edge 的外部推送服务可能拒绝临时测试订阅；遇到这一结果只验收故障提示和独立的订阅 API 写入/关闭，不冒充真实通知送达。真实生产推送与设备送达仍在后续路线待办。

新增浏览器错误回归覆盖 InvalidAccessError、InvalidCharacterError 和 AbortError：逐一确认中文提示、按钮可重试、未显示开启状态，并检查没有发送订阅写入请求。
